\section*{1. Why a Graph-Based Approach?}
Financial fraud rarely stays confined to a single transaction. Illicit money moves through networks of accounts, merchants, and devices, forming subtle ``rings'' that traditional tabular models fail to capture. By modeling the financial ecosystem as a heterogeneous graph (nodes = customers, merchants, devices; edges = transactions, shared attributes), the model captures relational, topological patterns to separate genuine activity from coordinated fraud rings.

\section*{3. Key Contributions}
\begin{enumerate}
  \item \textbf{Cycle Feature Engineering:} Designed a random-walk return probability extractor yielding localized topological representations of circular fund transfers without graph size explosion.
  \item \textbf{Attention-Driven GraphSAGE:} Built \texttt{CycleAwareSAGEConv}, a modular layer combining message-passing with learned attention over structural edge cycle motifs.
  \item \textbf{End-to-End AML Workflow:} Automated data prep, hyperparameter tuning, validation, and container-ready deployment supporting CPU and GPU.
  \item \textbf{Production-Grade API Design:} Implemented deterministic validation ordering where schema/column completeness is verified before model checks, ensuring clear error reporting.
  \item \textbf{Interactive Web Application:} Delivered a full-stack demo with a Vite/React interface connected to FastAPI for real-time inference and suspicious ring visualization.
  \item \textbf{Reproducibility \& Rigor:} Full ablation suites with standardized test harnesses, detailed LaTeX documentation (\texttt{main.tex}), and zero data leakage.
\end{enumerate}

\section*{4. Quantitative Impact \& Scalability}
\begin{itemize}
  \item \textbf{Detection Gains:} On financial benchmark data, cycle-aware GraphSAGE improves PR-AUC from \textbf{0.78} to \textbf{0.85} and increases Ring Recall@10 by \textbf{12\%}.
  \item \textbf{Scalability:} Random-walk cycle extraction runs in $\mathcal{O}(|E| \log |V|)$ time, processing million-edge graphs within standard memory constraints.
  \item \textbf{Operational Usability:} Clear API error contracts and interactive graph UI simplify triage for anti-money laundering (AML) compliance analysts.
\end{itemize}
